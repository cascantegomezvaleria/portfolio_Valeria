# Valeria Cascante – Portfolio

Personal portfolio built with HTML, CSS and JavaScript.

```
index.html, styles.css, script.js   ← portfolio
knight/                              ← "A Knight of the Seven Provinces" demo store
  index.html
  CSS/estilos.css
  js/products.js   ← edit the catalogue here
  js/index.js      ← filters, cart, greeting, mobile menu
  js/slider.js     ← reviews slider
  js/questions.js  ← FAQ accordion
  Images/
```

Open `index.html` in VS Code with the Live Server extension (or double-click it) to view the site.
